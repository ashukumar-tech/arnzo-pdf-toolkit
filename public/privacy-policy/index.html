Privacy Policy

Last updated: 23 November 2026

ARNZO PDF Toolkit is designed to process selected documents inside your browser. The PDF and image files you choose are handled locally by the application and are not intentionally uploaded to ARNZO servers for conversion.

Files and local processing

File operations such as merging, splitting, rotating, extracting, image conversion and raster-based compression run in your browser. Your files remain under your device and browser control. Closing the tab or clearing browser memory removes the working session.

Website infrastructure

The website is delivered through Cloudflare Pages. Like most websites, hosting, security and delivery infrastructure may process technical request information such as IP address, browser details, requested URL and timestamps in connection with operating and protecting the service. ARNZO does not use this PDF tool to inspect the contents of your documents.

Third-party services

The application uses open-source browser libraries for PDF and image processing. The interface may load web fonts from Google Fonts. Those third-party services operate under their own privacy terms.

Retention and security

ARNZO does not maintain a server-side document storage area for files processed by this tool. Do not use a shared or compromised device for confidential documents. Local processing reduces file transfer but does not remove risks from malware, browser extensions, screenshots or device access.

Children and contact

This tool is a general-purpose utility and is not designed to collect personal information from children. For questions about this policy, use the contact options on the ARNZO website.

This page describes the current browser-based tool. It is general privacy information, not legal advice.
